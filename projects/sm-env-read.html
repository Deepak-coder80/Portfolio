sm_env_read

AWS Secrets Manager helper that handles the authentication complexity for you. Tries direct credentials first, falls back to STS role assumption automatically. Async/await native, with ready-made Django and FastAPI integration patterns.

PyPI → GitHub Issues

Why this exists

AWS Secrets Manager auth has a non-obvious quirk: sometimes you have direct credentials, sometimes you need to assume a role via STS. Handling both cases correctly - including the fallback logic - takes more boilerplate than it should. This package wraps it into one async function call.

Auth complexity handled

  • Tries direct AWS credentials first
  • Falls back to STS role assumption automatically
  • Works across ECS, EC2, Lambda, and local dev

Framework integration

  • Django: load at settings.py startup
  • FastAPI: load in startup_event lifecycle hook
  • Flask: load at application factory time

Production reliability

  • Meaningful error messages per failure mode
  • JSON string and binary secret format support
  • Minimal dependencies - just boto3

Features

⟳

Dual auth

Direct credentials first, STS role assumption fallback - handled transparently.

◎

Async native

Built with async/await. Non-blocking secret retrieval for FastAPI and async Django.

△

Error classes

Specific exceptions for each failure mode - auth, not found, access denied, network.

⬡

Format support

JSON string secrets and binary secrets both supported with automatic detection.

◈

Framework ready

Drop-in examples for Django settings, FastAPI startup events, and Flask app factories.

○

Minimal footprint

Only boto3 and botocore. No version conflicts with your existing AWS stack.

Usage

Basic usage
import asyncio from sm_env_read import get_env_secrets_from_sm async def main(): secrets = await get_env_secrets_from_sm( account_id="123456789012", region="us-east-1", role_name="MySecretsRole", secret_name="my-app/prod/secrets" ) db_password = secrets.get("database_password") asyncio.run(main())
Django settings.py
import asyncio from sm_env_read import get_env_secrets_from_sm secrets = asyncio.run(get_env_secrets_from_sm( account_id="123456789012", region="us-east-1", role_name="DjangoSecretsRole", secret_name="django/prod/secrets" )) DATABASES = { 'default': { 'ENGINE': 'django.db.backends.postgresql', 'NAME': secrets.get('db_name'), 'USER': secrets.get('db_user'), 'PASSWORD': secrets.get('db_password'), 'HOST': secrets.get('db_host'), } } SECRET_KEY = secrets.get('django_secret_key')
FastAPI startup event
from fastapi import FastAPI from sm_env_read import get_env_secrets_from_sm app = FastAPI() @app.on_event("startup") async def startup_event(): app.state.secrets = await get_env_secrets_from_sm( account_id="123456789012", region="us-east-1", role_name="FastAPISecretsRole", secret_name="fastapi/prod/secrets" )
Required IAM permissions
{ "Action": [ "secretsmanager:GetSecretValue", "sts:AssumeRole" ], "Resource": [ "arn:aws:secretsmanager:REGION:ACCOUNT:secret:SECRET_NAME*", "arn:aws:iam::ACCOUNT:role/ROLE_NAME" ] }

How it works

Auth fallback logic

Attempts GetSecretValue with the current session credentials first. If that fails on auth, it assumes the specified IAM role via STS and retries.

Async architecture

Uses aiobotocore under the hood for non-blocking AWS API calls. Compatible with asyncio, FastAPI, and Django async views.

Secret format handling

Detects whether the secret is a JSON string or binary automatically. Returns a dict for JSON secrets, bytes for binary.

Security practices

Credentials are never logged. Error messages include the failure mode without exposing secret values or ARNs in plain text.
