ecr-deploy

Deploying Docker images to AWS ECR is a five-step manual process. This CLI turns it into one command - repo creation, authentication, build, and push - with multi-profile and multi-region support out of the box.

GitHub → Releases Issues

Why this exists

ECR deployment without this tool: check if repo exists, create it if not, run aws ecr get-login-password, pipe to docker login, build with the full ECR URI tag, push. That's five commands, each with flags you have to look up. This collapses it to one.

DevOps automation

  • Auto-creates ECR repo if it doesn't exist
  • Handles Docker auth, build, and push atomically
  • Works across Linux, Windows, macOS

CI/CD ready

  • GitHub Actions, Jenkins, GitLab CI examples included
  • Multiple AWS profile support per environment
  • Returns full image URI for downstream steps

Developer experience

  • Interactive mode with guided prompts
  • Pre-built binaries - no Go toolchain needed
  • Colored output with clear error messages

Features

⟳

Auto repo creation

Creates the ECR repository automatically if it doesn't exist in the target region.

⬡

Multi-profile AWS

Use different AWS profiles for dev, staging, and production in the same command.

◎

Flexible tagging

Custom tags, Git SHA, or default latest - your versioning strategy, not ours.

△

Multi-region

Deploy to any AWS region with a single flag. No config file changes needed.

◈

Interactive + CLI modes

Guided prompts for manual runs. Full flag control for automation.

○

Returns image URI

Outputs the full ECR URI on completion - pipe it directly into your deploy step.

Installation

Linux / macOS (one-line)
curl -sSL https://raw.githubusercontent.com/Deepak-coder80/ecr-deploy/main/install.sh | bash
Linux - manual
wget https://github.com/Deepak-coder80/ecr-deploy/releases/latest/download/ecr-deploy-1.0.0-linux-amd64.tar.gz tar -xzf ecr-deploy-1.0.0-linux-amd64.tar.gz sudo cp usr/local/bin/ecr-deploy /usr/local/bin/
Windows (PowerShell - Administrator)
Invoke-WebRequest -Uri "https://raw.githubusercontent.com/Deepak-coder80/ecr-deploy/main/install.ps1" | Invoke-Expression

Usage

Basic deployment
ecr-deploy --repo my-web-app ecr-deploy --repo my-api --profile production ecr-deploy --repo my-service --region eu-west-1 --tag v2.1.0
Environment-specific deployments
# Dev - tag with Git SHA ecr-deploy --repo my-app --profile dev --tag dev-$(git rev-parse --short HEAD) # Staging ecr-deploy --repo my-app --profile staging --region us-east-1 --tag staging-v1.2.3 # Production ecr-deploy --repo my-app --profile prod --region us-east-1 --tag v1.2.3
GitHub Actions integration
- name: Deploy to ECR run: | wget -q https://github.com/Deepak-coder80/ecr-deploy/releases/latest/download/ecr-deploy-1.0.0-linux-amd64.tar.gz tar -xzf ecr-deploy-1.0.0-linux-amd64.tar.gz sudo cp usr/local/bin/ecr-deploy /usr/local/bin/ IMAGE_URI=$(ecr-deploy --repo ${{ github.event.repository.name }} --tag ${{ github.sha }}) echo "IMAGE_URI=$IMAGE_URI" >> $GITHUB_ENV

How it works

Built with Go

Native AWS SDK v2 integration. Cobra CLI framework. Cross-compiled binaries for all major platforms with no runtime dependencies.

AWS SDK integration

Direct ECR API calls for repo management, STS for credential validation, and proper session handling across multiple profiles.

Docker automation

Orchestrates docker login, build with correct ECR URI tagging, and push - handling the authentication token refresh automatically.

Error handling

Every AWS and Docker failure returns a clear, actionable error message. No silent failures, no ambiguous exit codes.

Use ecr-deploy

Stop writing the same five ECR deployment commands in every project. One binary, one command, cross-platform.
